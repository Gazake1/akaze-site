# Akaze — download page

Site: **https://gazake1.github.io/akaze-site/**

This is the download page for [Akaze](https://github.com/Gazake1/AkazeClicker), a small and transparent
autoclicker for Minecraft on Windows, made in Brazil.

The executables are published as GitHub Releases of the main repository
([Gazake1/AkazeClicker](https://github.com/Gazake1/AkazeClicker/releases)), built by GitHub Actions. The page always links to
the latest release and reads its version, date, size and SHA-256 hashes automatically.

The page is a single `index.html` (English by default, Portuguese with the flag switch in the corner or `?lang=pt`).
